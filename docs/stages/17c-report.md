## 3. What was not tested, and the risks

- **The figure is 1.6 world units tall — the profile's height, unchanged — while the silhouette it replaces
  drew about 2.6.** `SpinePlayerView` always draws at `TargetHeightWorld` (a scaled parent is compensated),
  so the camp's figure cannot be sized without changing the profile the arena shares. It reads correctly
  against the shelves in the two captures, but "is the doctor too small in the sala" is an art call nobody
  has made; the lever is the profile's `targetHeightWorld`.
- **The published figure rect is the anchor's box, not the drawn figure's.** `TryGetPlayerScreenRect`
  projects the (now disabled) placeholder renderer — 245 × 260 px at 1080p — because the stage's brief was
  not to touch the geometry document. The world coordinates are exact; the box is ~1 unit taller than the
  figure. Fixing it means projecting the actor's mesh bounds.
- **No browser assertion covers the figure.** `__projectSurviveCamp` gained no `spine*` field (deliberately:
  the brief says the two documents stay as they are), so `tests/web/camp.spec.ts` proves the camp still
  behaves — walking, renting, the panel, the layout at both sizes — but not that the doctor in the built
  player is the Spine one. The Battle document is where that check lives (17b).
- **One pose picture came from a synthetic key state.** The Pipeline's `simulate_key`/state event does not
  hold a key while the Editor is unfocused (the native device's own state overrides it between input
  updates), so the walking capture was taken from a queued `KeyboardState(D)`: the figure moved and the run
  animation played, but the frame is not a human holding `D`. The behaviour itself is measured by the
  PlayMode case with `InputTestFixture`.
- **The spine renderer's cost in the camp was not measured.** One actor, one material, no number.
- **The art still has no licence** (`ATTRIBUTION.md`): the Camp scene now draws it too, so 17c widens that
  blocker by one scene.
- **The scene file was regenerated**, so its diff is a whole-file rewrite (new local ids) like Stage 09o's.
  Its content is what the builder produces; every scene-reading test and the UI capture ran against it.
